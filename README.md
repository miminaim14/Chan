#Description

This program allows user to input a sentence, then calculates the total word count and computes the total character count including spaces. 

#How to run

1.Open the project in PyCharm.
2.Right click the main.py and run the main.
3.Enter a sentence and press enter button.

#Test results

1.For Normal Sentence Test, the sentence is "My name is Syamimi Auni and this is my first CSC649 class". The outputs is word count is 12 and character count including spaces is 57.
2.For Enter Space Test, the sentence is "My name is        Syamimi       Auni". The outputs is word count is 5 and character count including spaces is 39.
3.For Empty Input Test, the sentence is "". The outputs is You did not enter a sentence.

#Limitation

Punctuation marks attached to words and stand-alone symbol are counted as part of the word count."# Chan"
